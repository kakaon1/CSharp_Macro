# C# 매크로

마우스/키보드 동작을 기록하고 자동으로 재생하는 Windows 매크로 프로그램입니다.

---

## 기능

| 기능 | 설명 |
|------|------|
| 전역 핫키 | 프로그램에 포커스 없이도 F6/F7/F8로 제어 |
| 마우스 클릭 기록 | 좌클릭 / 우클릭 좌표 자동 기록 |
| 마우스 위치 기록 | F8 — 현재 커서 위치를 이동 액션으로 기록 |
| 키보드 입력 기록 | 키 입력을 매크로로 저장 |
| 자동 저장 | 녹화 종료 시 `%AppData%\CMacro\autosave.json`에 자동 저장 |
| 반복 재생 | 재생 횟수 지정 가능 |
| 딜레이 제어 | 녹화된 딜레이 포함/제외 선택 |
| 프로그램 실행/종료 | 찾아보기로 실행 파일 지정 후 실행 및 강제 종료 |
| 파일 저장/불러오기 | JSON 형식으로 매크로 파일 관리 |

---

## 핫키

| 키 | 동작 |
|----|------|
| **F6** | 녹화 시작 / 중지 |
| **F7** | 재생 시작 / 중지 |
| **F8** | 현재 마우스 위치 기록 (녹화 중) |
| **Del** | 목록에서 선택 항목 삭제 |

---

## 빌드

- .NET 8.0 / Windows Forms
- Visual Studio에서 **Release 모드로 빌드** (자동 게시)
- 출력: `bin\Release\Publish\Macro.exe` (단일 실행 파일)

```powershell
# CLI 빌드
dotnet build Macro.csproj -c Release --no-restore
```
